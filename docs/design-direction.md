# 视觉与体验方向

**状态：草案，等待杨玉峰亲自审核。**

## 1. 设计目标

页面要有明确的个人气质，不像通用作品集模板，也不做传统简历式长页面。视频与图片共同构成作品空间，整体感受应克制、成熟、有影像质感。

“高级感”主要来自：真实素材质量、画面尺度、留白、字体层级、动效节奏和细节一致性；不依赖大量渐变、玻璃卡片或装饰粒子。

## 2. 第一段体验

- 开场节奏：`HELLO.` → `YANG YUFENG` → 直接进入作品
- 总时长保持短促，不设置百分比进度条
- 不使用独立加载 Logo 抢占注意力
- 开场后立即能看到姓名、定位、作品入口和导航
- 同一浏览会话只播放一次，并尊重减少动态设置

参考 Gavin 与 Tomoya 的短文字节奏，只借鉴进入方式，不复制页面、Logo 或素材。

## 3. 页面结构

- 首页首先展示作品，而不是大段个人履历
- 重点作品使用较大画幅，其余作品进入轻量索引
- 作品总量目标为 10–15 个，横屏、竖屏、视频和图片都要适配
- 分类为影像、AI 视频、摄影、设计与交互
- 全屏导航集中说明“我是谁、我会什么、关于我、如何联系”
- 点击作品进入全屏观看空间，不增加冗长案例详情页

作品组织借鉴 Electra 的大小网格、分类索引与全屏播放思路，但不复制其源码、品牌或媒体。

## 4. 媒体表现

- 封面负责第一眼构图，短预览负责建立动态感，全片由用户主动打开
- 视频与图片应处于同一视觉体系，不把图片当作低一级占位内容
- 重点项目优先选择商业影像、AI 视频、摄影各一个，体现能力跨度
- 真实媒体未到位前只使用明确占位，不虚构客户、成绩或账号数据

## 5. 动效语言

- 光标流体反馈应贯穿桌面作品空间，而不是只出现在局部区域
- 流体更适合轻微影响文字、图标或按钮反馈，不增加塑料感粒子球
- 菜单与播放器采用渐显、遮罩或两侧滑入，形成统一的场景转场
- 不是所有区块都需要飞入；动效应帮助观看层级，而不是持续抢注意力
- 触屏、减少动态和 WebGL 不可用时必须保留清晰、完整的静态体验

## 6. 色彩与字体

- 最终色板、字体和构图必须结合真实作品后再定
- 橙色目前是允许选项，不是默认色，也不是禁用色
- 如果后续判断橙色不适合，再把决定和原因写入 `decision-log.md` 的“已舍弃”部分
- 科技蓝绿色不作为默认方向，但可以在真实素材证明合适时重新评估
- 色彩选择必须服务作品与个人气质，不能为了显得高级而牺牲媒体本身

## 7. 当前待确认

- 最终主色、强调色和背景明度
- 中英文字体组合
- 个人肖像的拍摄与裁切方式
- 横屏和竖屏重点作品的实际比例
- 流体强度、转场速度和手机端降级细节

这些内容在真实素材到位后再确认，本阶段不做 A/B 方案。
