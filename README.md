# 杨玉峰作品集 v2

独立的 Vite + React + TypeScript 作品集原型，定位为“杨玉峰｜影像导演 × AI 视觉创作者”。当前内容层提供可替换项目占位数据，不包含真实作品媒体、肖像、邮箱或微信二维码。

## Local development

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` and update `VITE_MEDIA_BASE_URL` when media is available. Run checks with `npm run test:run`, `npm run typecheck`, `npm run lint`, and `npm run build`.
